## 第十九轮 · 备忘详情抽屉重做

用户截图说「查看备忘详情的抽屉样式没有改」。核对后：上一轮的改动确实在盘上
（`.facts` 圆角信息板已删、`StatusPill` 已换掉），但**结构没变**——还是「标题 + 一行灰字 + 三段文字」，
远看仍是深色面板堆几行字，所以主观上等于没改。这轮动的是结构。

### 报头：把页头那套搬到抽屉里
`Sheet` 新增 `<slot name="head">`（不传就走原来的「衬线标题 + 一行说明」，规则/事实抽屉不受影响）。
详情抽屉用它排出「印章（分类，带品红方点）→ 渐隐细线 → 记录于 …」，下面 27px 衬线标题。
页头、抽屉报头现在是同一套排布，这是「换面不换语言」。

### 正文：三段改成清单
- 状态仍是「圆点 + 字」（胶囊在暗底上没有对比）。
- 截止时间：衬线 22px「明天 · 19:00」，星期拆成 11px 无衬线小字（中文衬线 11px 会糊），
  下面接相对时间。今天/明天/后天走相对词，逾期走绝对日期。
- 提醒 / 变更：去掉 `.plan-title` 那套，统一成 `.blk-title` 的「微标签 + 引导线 + 右侧计数」。
- **修掉一处真 bug**：没有截止时间时，截止块写「没设截止时间，这条只存档」、
  提醒块紧接着写「没设截止时间，这条不会提醒」，同一句话连说两遍。
  现在没有截止时间就整段不渲染提醒，文案并成一句「没设截止时间，也不会提醒」。

### 顺手
- `dayDiff()` 从 `MemoEditor` 提进 `utils/datetime.ts` 导出（原先只有编辑器内部一份，详情要复用就得复制，
  两份日期数学迟早算岔）；编辑器改为 import。
- 复核深色面文字对比度：`--on-dark-3` 0.46→0.5（约 5.1:1）、`on-dark-2` 9.3:1、
  `#f2799f`（QQ 里改的）6.9:1，都过 AA。

## 第二十轮 · 抽屉统一为纸面（去掉深色材质）

用户澄清：「备忘详情的黑白色调与外面的暖纸风格不协调」。也就是说问题不在排版，
而在我上一轮自己立的规矩——「看=深色 / 写=纸白」。深色详情抽屉压在暖纸页面上，
两种材质直接对撞。

### 改法：删掉这条规矩
- `Sheet` 去掉 `tone` 属性，`.panel` 只有一种材质：
  `linear-gradient(180deg, var(--bg-top), var(--bg) 42%)` + 发丝线顶边 + `--ink` 文字。
  顺带删掉 `.panel.dark` / `.panel.light` / `.panel.dark .foot` 三处覆盖，
  关闭钮直接是纸白圆 + 发丝线（原来还有一套 `#2c2c2e` 深色底）。
- 5 处调用点去掉 `tone="light"`：DateTimePicker / MemoEditor / MemoryView ×2 / RulesView。
- 三个原本默认深色的抽屉全部落到纸面：MemoDetail、FilesView 文件详情、DigestPopup。
  DigestPopup 本来就用纸面令牌（`--ink-3` / `--accent-ink`），只是画在黑底上，改完即对。

### 连带清理
- `ImportanceMark` 的 `inverse` 分支（深色面上的白竖条）没人用了，删。
- `style.css` 里 `.btn-on-dark` / `.btn-paper` 没人用了，删——留着就是下一轮「改了一个漏了另一个」的伏笔。
- 文件详情抽屉的 `.facts` / `.detail-list` 从「白卡堆叠」改成发丝线清单，和备忘详情一致。
- 新增 `SheetHead.vue`：印章 → 细线 → 微标注 + 27px 衬线标题。MemoDetail 与 FilesView 共用，
  印章复用全局 `.eyebrow`。原来这套报头 CSS 只写在 MemoDetail 里。
